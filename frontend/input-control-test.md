# 输入框环节控制测试清单

## 测试目标
验证输入框在不同游戏环节的启用/禁用状态是否正确。

## 测试环境
- 游戏 URL: http://localhost:8080/index.html
- 测试角色：任意角色

## 测试步骤

### 测试 1：自我介绍环节 ❌ 禁止输入

1. 选择角色并进入游戏
2. 到达自我介绍环节
3. **验证**：
   - 输入框显示为灰色（禁用状态）
   - 占位符文字显示："自我介绍环节暂不可发言"
   - 发送按钮禁用
   - 无法在输入框中输入文字

### 测试 2：第一轮圆桌讨论 ✅ 允许输入

1. 等待自我介绍环节结束
2. 进入第一轮圆桌讨论
3. **验证**：
   - 输入框变为可用（白色背景）
   - 占位符文字显示："输入您的发言...（使用 @角色名 可以指定回复）"
   - 发送按钮启用
   - 可以正常输入并发送消息
   - 消息只显示一次（不重复）

### 测试 3：第一轮搜证环节 ❌ 禁止输入

1. 点击"结束讨论，进入下一环节"按钮
2. 进入第一轮搜证环节
3. **验证**：
   - 输入框再次禁用
   - 占位符文字显示："搜证环节暂不可发言"
   - 发送按钮禁用
   - 无法输入

### 测试 4：第二轮圆桌讨论 ✅ 允许输入

1. 完成搜证后进入第二轮讨论
2. **验证**：
   - 输入框重新启用
   - 可以正常发言
   - 消息只显示一次

### 测试 5：第二轮搜证环节 ❌ 禁止输入

1. 进入第二轮搜证
2. **验证**：
   - 输入框禁用
   - 占位符显示搜证提示

###测试 6：投票环节 ❌ 禁止输入

1. 完成所有讨论和搜证后进入投票
2. **验证**：
   - 输入框禁用
   - 占位符显示："投票环节暂不可发言"

## AI 扮演玩家测试

### 测试 7：AI 不应扮演玩家角色

1. 选择"杏儿花"作为玩家角色
2. 在讨论环节发送消息
3. **验证**：
   - AI 回复中不包含"杏儿花"的对话
   - 只有其他 NPC（薛名医、小马、李四、夏仙姑、吴村霸）的对话
   - 查看浏览器控制台，如果 AI 生成了玩家对话，应显示过滤日志：
     ```
     [regenerate_script] ⚠️ Filtered out X player messages from 杏儿花
     ```

## 预期结果总结

| 环节 | 输入框状态 | 占位符文字 |
|------|-----------|-----------|
| 自我介绍 | ❌ 禁用 | "自我介绍环节暂不可发言" |
| 讨论 1 | ✅ 启用 | "输入您的发言..." |
| 搜证 1 | ❌ 禁用 | "搜证环节暂不可发言" |
| 讨论 2 | ✅ 启用 | "输入您的发言..." |
| 搜证 2 | ❌ 禁用 | "搜证环节暂不可发言" |
| 投票 | ❌ 禁用 | "投票环节暂不可发言" |

## 快速验证命令

打开浏览器控制台，输入以下命令查看当前状态：

```javascript
// 查看当前环节
console.log('当前环节:', gameState.currentPhase);

// 查看是否在讨论中
console.log('讨论模式:', isInDiscussion);

// 查看输入框状态
const input = document.getElementById('player-input');
console.log('输入框禁用:', input.disabled);
console.log('占位符:', input.placeholder);

// 手动刷新输入状态
updateInputState();
```
